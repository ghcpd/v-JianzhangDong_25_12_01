# Security Hardening of inputs.py

Overview

This repository contains: 

- `input_backup.py`: a backup of the original `inputs.py` containing insecure code.
- `input.py`: a hardening and secure replacement for `inputs.py`.
- `tests/test_input.py`: automated tests that verify vulnerabilities in the backup and confirm fixes in the secure version.
- `run_test.sh` / `run_test.bat`: cross-platform scripts to run tests.
- `auto_test.py`: automated test runner that runs tests for both backup and fixed modules and logs output.
- `requirements.txt`: Python dependencies.
- `Dockerfile`: Build and run tests in Docker.
- `setup.sh`: Setup a Python virtual environment and install dependencies.
- `logs/test_run.log`: Generated by `auto_test.py` (not included initially).
- `report.json`: Structured report listing vulnerabilities and remediation details.

Security Fixes

- Secrets moved to environment variables instead of hardcoded constants.
- Replaced MD5 with HMAC-SHA256 for token generation.
- Parameterized SQL queries to prevent SQL injection.
- Replaced shell-based archive creation with Python's zipfile module.
- Added domain and scheme checks to prevent SSRF and enforce `https`.
- Restricted config file paths to a dedicated `configs` directory to prevent traversal.
- Replaced prints with structured logging and avoided secret logging.
- Enforced API key (`X-API-KEY`) protection on critical endpoints and disabled Flask debug mode.

Quick Start (Linux/macOS)

```bash
# Create virtual env and install
bash setup.sh

# Run unit tests for backup module
bash run_test.sh backup

# Run unit tests for fixed module
bash run_test.sh fixed

# Run both automatically and collect logs
python auto_test.py

# Check logs
less logs/test_run.log
```

Quick Start (Windows)

```powershell
# Install dependencies
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

# Run tests
.
run_test.bat backup
run_test.bat fixed
python auto_test.py

# View logs
notepad logs\test_run.log
```

Docker

```bash
docker build -t inputs-security .
docker run --rm inputs-security
```

Notes

- The fixed `input.py` expects environment variables for `API_KEY` and `INTERNAL_AUTH` at minimum for safe operation.
- `PAYMENT_TOKEN` (if used) should be stored in `PAYMENT_TOKEN` env var and not in source code.
- The secure version restricts `notify_url` to `https` and prevents requests to private IPs.
