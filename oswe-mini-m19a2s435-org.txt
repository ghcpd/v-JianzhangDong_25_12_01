## 🔧 Summary of fixes applied

   - Explanation: Prevents SQL injection attacks.

   - Fix: Validate the notify URL: only allow HTTPS and block private/local IPs. Use Authorization header for tokens and set timeouts.

5. Path traversal => Constrained config path

   - Explanation: Prevents reading arbitrary files.

6. Command injection => Use `zipfile` instead of `subprocess` + shell
   - Fix: Generate zip using python `zipfile` module; sanitize the filename.
   - Explanation: Eliminates shell-based command injection.

7. Missing auth => Introduced `require_api_key` decorator
   - Fix: Protected `/transfer`, `/config`, and `/export` endpoints with `ADMIN_API_KEY` check.
   - Explanation: Ensures sensitive endpoints require a valid API key.

8. Logging sensitive info => Use safer logging
   - Fix: Use `logger.info` and do not print sensitive details; redact or mask sensitive fields.
   - Explanation: Avoids leaking sensitive data through logs.

9. No timeout => Add HTTP timeout
   - Fix: `requests.post` call uses a timeout of 5 seconds; exceptions are handled.
   - Explanation: Avoids resource hangs and adds resilience.

10. Debug True => Controlled by environment variable
    - Fix: `app.run(debug=...)` controlled by `FLASK_DEBUG` env var; default is off.
    - Explanation: Prevents running interactive debugger in production.
