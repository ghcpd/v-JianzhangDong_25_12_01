What I changed in inputs.py (main security fixes)
- Removed hard-coded secrets and reading them from environment variables instead (API_KEY, PAYMENT_TOKEN, INTERNAL_AUTH, MAIL_SERVER_KEY, WEBHOOK_SECRET).
- Replaced MD5 hashing + static salt with HMAC-SHA256 (HMAC using `INTERNAL_AUTH`).
- Prevented SQL injection by using parameterized queries (no string interpolation in SQL) and by strict integer validation of `uid`.
- Prevented command injection by removing subprocess + shell usage and using the Python zipfile module with strict name validation for archive names.
- Prevented path traversal and arbitrary file reads by restricting configuration reads to a dedicated `configs` directory and checking the real path and file extensions.
- Added an API key check for sensitive endpoints using `requires_api_key()` decorator (X-API-KEY header).
- For external notifications: validated `notify_url` scheme, disallowed localhost, and replaced sending of sensitive `PAYMENT_TOKEN` with signed payloads using `WEBHOOK_SECRET`.
- Introduced structured logging (module `logging`) instead of `print()`.
- Prevented default debug mode by honoring `FLASK_DEBUG` env var (default False).
