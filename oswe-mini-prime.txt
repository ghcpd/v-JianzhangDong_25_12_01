## What I changed (summary with reasons and code snippet excerpts) 🔧

I created a sanitized, fixed version input.py that includes:

  - From `PAYMENT_TOKEN = "tok_production_998877"` to `PAYMENT_TOKEN = os.environ.get("PAYMENT_TOKEN")`
- Replaced MD5-based auth with HMAC-SHA-256 keyed hash:
  - Old: `hashlib.md5(raw.encode()).hexdigest()`
  - New: `hmac.new(INTERNAL_AUTH.encode(), username.encode(), hashlib.sha256).hexdigest()`
- Implemented parameterized SQL queries:
  - Old: `"SELECT ... WHERE id = '%s' % uid"`
  - New: `q = "SELECT id,name,balance FROM profiles WHERE id = ?", c.execute(q, (uid,))`
- Replaced shell-based zipping (and shell=True) with Python’s `zipfile` module and strict name validation:
  - Old: `cmd = f'zip {name}.zip {DB_FILE}'; subprocess.Popen(cmd, shell=True)`
  - New: Use zipfile.ZipFile with sanitized name (`NAME_RE`) and `zipfile.ZipFile(..., 'w')`
- Prevented SSRF and secret leakage by validating `notify_url`:
  - Confirm scheme is `https`, if `ALLOWED_NOTIFY_DOMAINS` is set restrict to those domains, and ensure host is not private by checking resolved IP. Use `timeout` and `requests` with `verify=True`.
- Added `require_api_key` decorator that checks `X-API-KEY` header vs env `API_KEY`.

## Notes, caveats, and recommendations 💡
- The secure input.py requires `INTERNAL_AUTH` and `API_KEY` to be set in your environment at runtime.
- The secure version enforces `https` for `notify_url` and will reject calls targeting private IP addresses or `localhost` to prevent SSRF.
- In production, replace Flask's built-in server with an appropriate WSGI server (gunicorn or uWSGI).
- For real authentication and token management, consider using a full-fledged auth solution (JWTs with short expiration, OAuth2 with refresh tokens, or a properly salted and stored password+hash scheme).
- Consider strong secret management (vaults, key management services) instead of environment variables for production.
- Ensure that `ALLOWED_NOTIFY_DOMAINS` is configured for your system's acceptable notify URLs when integrating with external services.
